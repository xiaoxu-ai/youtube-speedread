填一个 OpenAI 兼容接口（/v1/chat/completions）就能用。

AI 接口

填到 /v1 为止就行，后面的 /chat/completions 插件会自己接上。

保存在浏览器本地（storage.sync），只会发给你自己填的这个接口。

建议选上下文和输出都比较大的模型，长视频更稳。
翻译任务优先选「非推理」模型（如 deepseek-v4-flash）， 推理模型（deepseek-v4-pro、glm-5.1 等）会先花大量 token 内部思考，又慢又贵。

翻译参数

0 最死板，1 以上会开始发挥。翻译建议 0～0.5。

太小会把译文切断。不够时插件会自动加大重试。

字幕会切成小块分别翻译，避免一次性输出被截断。

越大越快，但容易触发接口限流。被限流就调回 1～2。

视频有多条字幕轨道时用哪条。选的语言不存在就自动回退。

GLM、Qwen 这类模型默认开着「思考」，会先花掉大量 token 做内部推理， 正文还没开始写额度就用完了 —— 表现就是「AI 返回内容为空」。 翻译不需要推理，建议保持勾选。
只会对识别得出的模型生效（模型名含 glm / qwen / deepseek / kimi-k 等）， OpenAI 之类的接口不会收到这个参数。
